# Personal Expense Tracker – Data Analysis Project

## Project Overview
This project analyzes personal expense data to understand spending patterns across different categories such as Food, Rent, Bills, Shopping, and more. The goal is to calculate meaningful metrics, create visualizations, and generate insights that help in budgeting and financial planning.

---

## Objectives
- Load and validate the dataset
- Clean and prepare the data for analysis
- Perform category-wise and monthly expense analysis
- Create at least two different types of visualizations
- Generate meaningful insights from the analysis
- Maintain professional documentation and formatting

---

## Dataset Description
The dataset contains monthly financial records of multiple users.

### Key Columns
- **UserID**: Unique identifier for each user  
- **Year**: Year of record  
- **Month**: Month of record  
- **Income**: Monthly income  
- **Expense Categories**:
  - Food
  - Groceries
  - Transport
  - Entertainment
  - Shopping
  - Rent
  - Bills
  - Healthcare
  - Education
- **Total_Exp**: Total monthly expenses  
- **Savings**: Remaining amount after expenses  

---

## Analysis Performed
### 1. Data Cleaning and Validation
- Verified dataset structure and columns
- Checked for missing values
- Verified numeric columns for correct formatting

### 2. Expense Analysis
- Calculated total spending by category
- Identified highest spending categories
- Calculated monthly expense trends

### 3. Insights
- Identified major expense contributors
- Observed monthly spending variations
- Analyzed relationship between income, expenses, and savings
